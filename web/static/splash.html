Welcome to Mavic Drone Shop

Here you will find our full fleet. Have a browse around and see who is here.

This is a simple example microservices ecommerce application, restyled as a drone marketplace. It has been built using various technologies:

  • AngularJS (1.x)
  • Nginx
  • NodeJS
  • Java
  • Python
  • Golang
  • PHP (Apache)
  • MongoDB
  • Redis
  • MySQL
When deployed into an environment monitored by Instana, these technology stacks will be automatically detected and monitored, all with minimum configuration. Every request will be traced end to end. Real-time metrics, events, and traces are tracked end to end across the fleet.

To find out more visit the Instana site.

Built on top of an open-source microservices demo architecture, adapted here as a drone marketplace for a DevOps portfolio project.
