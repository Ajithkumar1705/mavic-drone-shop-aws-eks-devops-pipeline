Here you will find our full fleet. Have a browse around and see who is here.

This is a simple example microservices ecommerce application, restyled as a drone marketplace. It has been built using various technologies:

  • AngularJS (1.x)
  • Nginx
  • NodeJS
  • Java
  • Python
  • Golang
  • PHP (Apache)
  • MongoDB
  • Redis
  • MySQL
Real-time metrics for each service are tracked via Prometheus and visualized in Grafana.

Built on top of an open-source microservices demo architecture, adapted here as a drone marketplace for a DevOps portfolio project.
